Shorts Studio

Shorts Studio is the private software the channel's owner uses to make these videos and to see how they do. With the owner's permission, it reads the channel's own video statistics (views, likes, comments) through the YouTube API Services, read-only, on the owner's own computer. It is not offered to anyone else, and it never reads anything about viewers.
